# A Small Fortune

A paper fortune picker inspired by Japanese omikuji. Pick a topic and draw a slip.

## About

A small personal project built to practice JavaScript. The theme, data and design is an omikuji-style fortune slip. Just for fun, not a real prediction.

## Features

- 8 topics: love, study, work, health, luck, travel, money and wish
- Lucky Draw option that picks a fortune from any topic
- Random fortune slips with a luck rank
- Popup slip with open and close animations

## Built With

- HTML
- CSS
- JavaScript

## What I Learned

- Filtering and picking random items from an array of objects
- Rendering HTML from data with template literals
- Handling events and keeping radio buttons and a checkbox in sync
- Keeping data (`data.js`) separate from logic (`index.js`)
- CSS animations for opening and closing animations
